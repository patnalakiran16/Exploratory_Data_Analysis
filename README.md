Task 30: Exploratory Data Analysis (EDA) Using Python

Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a sample Student Performance Dataset using Python. The main purpose is to understand the data, identify missing values, clean the dataset, perform basic statistical analysis, and find useful patterns through visualizations.

Objective

- Understand the structure of the dataset.
- Identify and handle missing values.
- Check and remove duplicate records.
- Perform basic statistical analysis.
- Create meaningful data visualizations.
- Identify important observations from student performance data.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

Dataset Description

A sample dataset containing 20 student records with the following columns:

Column Name| Description
Student| Student name/ID
Study_Hours| Daily study hours
Attendance| Attendance percentage
Previous_Score| Previous examination score
Final_Score| Final examination score

Steps Performed

1. Data Collection

Created a sample student performance dataset using Pandas.

2. Data Exploration

Checked the dataset shape, structure, information, and statistical summary.

3. Data Cleaning

- Checked missing values.
- Identified duplicate records.
- Removed duplicate records.
- Replaced missing numerical values with column averages.

4. Statistical Analysis

Calculated average study hours, average final scores, highest scores, and lowest scores.

5. Data Visualization

Created the following visualizations:

1. Histogram – Distribution of student final scores.
2. Scatter Plot – Relationship between study hours and final scores.
3. Bar Chart – Comparison of student performance.
4. Box Plot – Distribution of final scores.
5. Correlation Heatmap – Relationship between numerical variables.

Key Observations

1. Students have different study hours and academic performance levels.
2. The average final score helps understand overall student performance.
3. Students who study more hours generally tend to score higher in this sample.
4. Attendance and previous scores are useful factors for analysing academic performance.
5. The correlation analysis helps identify relationships between numerical variables.

Output

"cleaned_student_data.csv"
